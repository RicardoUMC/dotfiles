# Hyprland Lua configuration

## Goal
Replace the deprecated Hyprland `.conf` configuration with the native Lua format so the shell remains compatible with Hyprland 0.57+ and the deprecation warning disappears.

## Scope
- Add `hyprland/.config/hypr/hyprland.lua` equivalent to the current user configuration.
- Preserve monitor placement, workspace defaults, programs, autostart, environment, appearance, input, keybindings, and window rules.
- Keep the existing `.conf` file untouched until runtime verification confirms the Lua configuration loads.

## Acceptance checks
- `hyprland --verify-config --config <lua path>` succeeds on the installed Hyprland.
- The Lua config contains no autogenerated-warning call.
- `hyprctl`/runtime config discovery will prefer `hyprland.lua` without the `.conf` warning.
- Existing `.conf` behavior is represented, including DDC/CI brightness and Quickshell IPC commands.
